# Guía de Contribución

## Reglas para colaborar
- Crear una rama por funcionalidad
- Realizar commits frecuentes
- Documentar cambios importantes

## Nombres de ramas
Ejemplos:
- rama-header
- rama-chiapas
- rama-contacto

## Reglas para commits
Usar mensajes claros y descriptivos.

Ejemplos:
- Se agregó formulario de contacto
- Se mejoró diseño responsive
- Se corrigió error en navegación
